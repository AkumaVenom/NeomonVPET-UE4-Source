# NeomonVPET-UE4-Source

NeomonVPET is an offline virtual pet game created in Unreal Engine 4. Inspired by classic handheld monster-raising games, players can care for their Neomon by feeding, training, cleaning, and managing its hunger and strength.

The project includes multiple Neomon creatures, animated interactions, changeable backgrounds, music controls, persistent save data, and a simple desktop-friendly interface.

A ranked battle system is planned but is not currently implemented.

Current Features
Raise and care for different Neomon
Feed, train, and clean your Neomon
Hunger and strength systems
Multiple room backgrounds
Music and sound controls
Save-game functionality
Offline single-player gameplay
Built with Unreal Engine 4
Planned Features
Offline ranked battles
Expanded Neomon progression
Additional creatures and environments
Improved battle and training systems
